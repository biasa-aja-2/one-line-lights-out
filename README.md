One Line, Lights Out — a single status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. Its sadness comes from one small, exact detail of a machine's life — an unsent, half-typed reply and a blinking cursor — not from announced grief.

## Run it

```sh
python3 main.py
```
